# Logo Design — Formulaire de Brief Créatif Client

Application web moderne, responsive et personnalisable pour recueillir les briefs créatifs des nouveaux clients de l'agence **Logo Design** (Digital, Branding, Packaging, Print & 3D), **sans tarification**.

## Fonctionnalités principales

- **Parcours multi-étapes fluide (5 étapes)** avec barre de progression, validation des champs obligatoires et animations.
- **Thème Clair (grille studio) & Mode Sombre élégant** avec accents bleu électrique, vert émeraude, violet et doré.
- **Mode Éditeur Agence (« Modifier & Besoins »)** :
  - Ajouter, renommer, réorganiser, masquer ou pré-sélectionner des besoins / services.
  - Activer/désactiver des étapes (ex. masquer l'étape Impression pour un client 100% digital).
  - Ajouter des questions personnalisées à n'importe quelle étape.
  - Sauvegarder et charger des modèles prêts à l'emploi.
- **Partage client en 1 clic** : génération d'un lien unique `#brief=...` contenant vos personnalisations et pré-remplissages, prêt à être envoyé sur WhatsApp ou par e-mail.
- **Confirmation & Exports** :
  - Récapitulatif interactif (chaque section reste modifiable en un clic).
  - Copie du récapitulatif formaté dans le presse-papiers.
  - Envoi direct sur WhatsApp (`+212 771 66 34 35`) avec message pré-rempli.
  - Exportation PDF studio multi-pages (avec aperçus images intégrés).

## Lancement local

```bash
npm install
npm run dev
```

Pour compiler la version de production :

```bash
npm run build
```
